# Privacy Notice

This notice describes the limited data handling used by the resume-download flow on the portfolio website.

## When data is sent

The website shows a notice before a visitor continues with a resume download. A request is sent only after the visitor presses **Continue** in that dialog. The name and role fields are optional; leaving them blank does not prevent the download.

## Data included in the request

The request may include:

- Optional name and role or company
- Download timestamp
- Browser or recognized in-app browser category
- Operating system and device category
- Browser language and timezone
- Referring site origin, when available
- The portfolio page path

The website does not request an account login, password, payment data, or precise location.

## Purpose and delivery

This information is used to understand high-level portfolio interest and the context in which a resume is downloaded. The request is delivered through FormSubmit. The on-page download notice states that FormSubmit stores submissions for 30 days.

## Download availability

If the external delivery request fails, the resume download still proceeds. Visitors can also leave the optional text fields empty.

## Data minimization

Do not enter sensitive personal information in the optional fields. This repository must not contain credentials, submitted visitor records, or private contact data.
