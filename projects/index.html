Personalized Health Coach Multi-Agent

Architecture
프로젝트 보러가기View the project→
  • 개인 건강정보와 연구 근거를 바탕으로 생활습관을 안내하는 건강 코칭 챗봇을 개발했습니다.
  • Standard RAG는 복합 질문의 논문 근거를 놓치거나 근거가 부족해도 답변을 생성했습니다. Agentic RAG에서는 사용자 건강 상태를 반영해 검색 질의를 분해하고, Hybrid Retrieval로 찾은 근거를 선별 및 검증하며 부족하면 답변을 유보합니다.
  • Single-Agent는 식단과 운동의 복합 질문, 기록 조회와 응급 요청을 한 경로에서 처리하는 데 한계가 있었습니다. LangGraph Supervisor로 Diet, Exercise, Safety, Records, Writer Agent에 역할을 나누고, 식단과 운동 근거 검색은 병렬로 실행합니다.
  • 100개 메시지 평가에서 근거 회수율은 Standard RAG 31.6%에서 Agentic RAG 58.2%로 높아졌습니다. 코칭 외 요청 처리율은 Single-Agent 35.0%에서 Multi-Agent 97.5%로 높아졌습니다.
  • 별도 200문항 Benchmark에서 최종 시스템은 181문항(90.5%)을 통과해 Single-Agent의 165문항(82.5%)보다 16문항 높았습니다. API 오류는 0건이었습니다.

LangGraph Multi-Agent, Supervisor Routing, Query Expansion, Hybrid Search RAG, Evidence Citations, Safety Rules
